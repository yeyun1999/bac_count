# bac_count — 平板菌落计数

PySide6 + OpenCV 的培养皿菌落自动计数工具：左侧预览标注，右侧参数面板，
多算法可切换、参数实时调整、支持手动增减菌落校正。

## 运行

```bash
uv sync                       # 首次安装依赖
uv run bac-count sample/      # 启动并打开样例文件夹（路径可选）
# 或
uv run python -m bac_count
```

## 使用速览

| 操作 | 方式 |
|---|---|
| 打开图片/文件夹 | 「📂 打开」菜单；或拖图片/文件夹到窗口 |
| 多图导航 | `◀` `▶` 按钮（Alt+←/→） |
| 文件列表 | 左侧 dock（`Ctrl+E` 折叠/展开）；**单击/双击/Enter 切换图片**；**Ctrl/Shift 多选（不切换图片）**；当前显示的图片**加粗**；Delete 键或右键菜单移除选中（不删磁盘文件）；支持清空 |
| 视图切换 | 图片**左上角**悬浮按钮：**原图 / 预处理**（预处理视图显示通道选择+模糊+CLAHE+极性后的灰度图并画出皿 ROI 红圈，方便调预处理参数）；**右上角**「显示标记」复选框独立控制菌落圈/编号叠加的显隐——两种视图都能开关标记 |
| 调参 | 右侧面板滑杆/下拉，~150ms 内自动重算；**参数按图片独立保存**——切回看过的图自动恢复它的参数，新图继承上一张的参数 |
| 参数解释 | 鼠标悬浮在参数名或控件上显示该参数的作用与调节方向 |
| 参数分组 | 按**检测执行顺序**排列七组可折叠面板：皿 ROI → 预处理 → 检测算法（选择+该算法参数）→ 粘连拆分 → 颜色过滤 → 后处理过滤 → 手动校正（点组标题折叠）；默认收起预处理/后处理过滤/手动校正，折叠状态跨会话记忆 |
| 复制参数 | 多选目标图（右键未选中项会**加选**、不清已有选区）→ 右键「复制当前图参数 → 选中项 (N)」，N=目标数、为 0 置灰；或「→ 全部其他图」。源 = 加粗的当前图 |
| 切换算法 | 面板"检测算法"组：全局阈值 / 自适应阈值 / Blob / Hough 圆 / HSV 颜色分割（取色式，见下） |
| 手动添加菌落 | 模式「添加」（快捷键 2），点击空白处；半径在面板"手动校正"组 |
| 手动删除菌落 | 模式「删除」（快捷键 3），点击菌落 |
| 粘连拆分 | 参数面板「粘连拆分」组勾选**拆分粘连菌落**（默认关）：距离变换+分水岭把大团拆为子菌落；「合并判定倍数」「分水岭峰值比」可调。碎片须与候选本体同色（防把贴住菌落的马克笔笔画拆成假菌落）。重叠超一半的极端粘连拆不动，用手动 |
| 颜色过滤 | 参数面板「颜色过滤」组（默认关）：点菌落颜色行的 **🎨** → 在图上点菌落实体取色（光标旁有**圆形放大镜**辅助对准，**按住空格可临时平移**；Ctrl+左键连取多个），颜色相差太远的候选被去掉；对培养基/马克笔字/气泡取「排除颜色」，相近的候选被去掉。各配 Lab 容差滑块。取色后自动开启；色块点击=移除。放在拆分后执行（拆出的碎片也参与颜色判定），对所有算法生效 |
| HSV 取色检测 | 「检测算法」选 **HSV 颜色分割**：不再调 6 个数值——点"菌落取色"行的 **🎨** 在菌落上采 1~3 个颜色 + 一个容差滑块即可。适合**灰度上没反差但颜色有反差**的平板（灰度算法看不见、颜色过滤无从筛起，只有它能"找"） |
| 去重重叠 | 「后处理过滤」组**合并重叠菌落**（默认开）：两圆交集超过小圆 60%（含大圆套小圆）判为同一菌落、保留大的——专治 Hough 双圈/重复圈；真正相邻的菌落只在边缘相交不会被误并，阈值可调 |
| 撤销/重做 | `↶` `↷` 按钮或 Ctrl+Z / Ctrl+Y |
| 缩放平移 | 滚轮缩放、浏览模式拖拽、中键任意模式平移、`0` 适应窗口 |
| 按住空格 | 任意模式下临时变为平移（手形）工具 |
| 按住 Ctrl | 添加↔删除模式临时互换（松开恢复） |
| 导出 | 「📤 导出」菜单，**对文件列表全部图片批量**（带进度/可取消）：标注图 PNG → 所选目录下 `annotated/`；汇总表 CSV → 一图一行（文件名/菌落数量/自动检出/手动添加/手动排除）；完整数据 JSON → 每图的路径、检测参数、菌落位置与编辑记录 |
| 预设/清除编辑 | 「⚙ 预设」菜单：保存、加载、恢复默认参数、清除当前图编辑；预设存 `~/.bac_count/presets/` |

RGBA 图片的透明区域自动作为培养皿外掩膜（皿缘按"皿缘内缩"比例再收缩）。
